# Config add plans
As well as adding devices to the config.yaml, you can add plans. Under the code you already have, add the following:

```
    - kind: planFunctions
      module: dodal.plans
    - kind: planFunctions
      module: dodal.plan_stubs.wrapped
```
These plans that will be used in this tutorial can be found in the [dodal repository](https://github.com/DiamondLightSource/dodal/tree/b4b38f1e0cf480faeb29d67695440c45a148f169). Specifically, in `dodal/src/dodal/plans/wrapped.py` and `dodal/src/dodal/plan_stubs/wrapped.py`.

Now run 
```blueapi controller plans``` in the same terminal as before and you should see a list of plans that can be run. For example, `count`, `list_grid_scan`, `num_scan` etc.


Now having added plans and devices to the `config.yaml` file, we need to restart the worker to use this file. Close the current worker (ctrl+C) and run this command:

```
blueapi --config path/to/file serve
```
If you have created the `config.yaml` file in the `resources` folder as suggested on the previous page, the command will be:

```
blueapi --config docs/resources/config.yaml serve
```
