# 4. Config add plans

As well as adding devices to the `config.yaml`, you can add plans. Under the code you already have, add the following:

``` yaml
    - kind: planFunctions
      module: dodal.plans
```
These plans that will be used in this tutorial can be found in the [wrapped plans folder in the dodal repository](https://github.com/DiamondLightSource/dodal/blob/main/src/dodal/plans/wrapped.py). By default, blueapi comes with some pre-loaded bluesky plans stubs too which can found in `/workspaces/blueapi/src/blueapi/core/context.py`. NB: these can be overwritten. For example, if a user makes a plan called `mv`, this will overwrite the `bps.mv` plan stub.

Save the changes you've made to the `config.yaml` file. Navigate back to the terminal where the blueapi worker is running. Restart the server to use this updated `config.yaml` file.

Now run 
```blueapi controller plans``` in the same terminal window used previously for this command and you should see a list of plans that can be run. For example, `count`, `list_grid_scan`, `num_scan` etc.
